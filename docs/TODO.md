## 仮決定と見直し

### 特別版は放送の 8 日以上前に番組表へ掲載される

- 根拠: 本人の体感（「急遽載るようなものではない」）。一次情報による裏付けはない
- なぜ仮決定か: NHK 番組表 API は 7 日先までしか取得できないため、「8 日以上前に掲載されているか」を API 経由で検証できない
- この前提が必要な理由: 週 1 サマリ方式は、サマリ送信時点で番組表に載っていない放送を通知できない。前提が外れると最大 6 日間気づけないまま放送が終わる
- 見直し時点: 週 1 サマリで通知されないまま特別版を見そびれる事象が発生したとき
- 外れた場合の対応: 日次実行＋前回になかった放送のみ通知する方式へ移行する。この場合、通知済み記録の保存先を決める必要がある
