# コンセプト

## 解く課題

ピタゴラスイッチには朝夕の定期放送があるが、たまにそれ以外の時間帯に特別版が放送される。特別版には予告がないため、番組表を能動的に確認しない限り気づけず、見そびれる。

放送予定を受け取ることで、この気づき漏れをなくす。

## 利用者

本人1名のみ。他者への提供・共有は想定しない。

## 利用シーン

日曜の夜、LINE に届いた翌週分の放送予定を見て、録画予約する。

放送はリアルタイム視聴ではなく録画で見るため、放送日の前日までに予定を把握できればよい。

## スコープ

NHK 番組表 API から対象期間のピタゴラ系放送を取得し、週 1 回 LINE へまとめて通知する。

```
NHK番組表API → 対象放送の抽出 → サマリ生成 → LINE通知
```

## やらないこと

| やらないこと | 理由 |
|---|---|
| 録画予約の連携 | レコーダー依存になり難易度が跳ね上がる。通知を受けて手動で予約すれば課題は解決する |
| カレンダー登録 | 通知だけで気づき漏れは解消する |
| 特別版の自動判定 | 番組名から特別版を判別できない。全放送を通知すれば判定ロジックが不要になる |
| 本人以外への通知・複数ユーザー対応 | 利用者は本人1名のみ |
| 画面・Web UI | 通知が届けば目的を果たす |
| 過去放送の閲覧 | 見そびれを防ぐ目的に対して過去は不要。API も過去日を提供しない |
| 放送データの永続保存 | NHK 番組表 API の規約で、情報提供期間を超えたデータの保持が禁止されている |
