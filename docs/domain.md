# ドメイン

## 用語

| 用語 | 定義 |
|---|---|
| 放送 | 番組表上の 1 回の放送枠 |
| ピタゴラ系 | 番組名に「ピタゴラ」を含む放送。`ピタゴラスイッチ` `ピタゴラスイッチ ミニ` `大人のピタゴラスイッチ` が該当する |
| 対象期間 | 取得実行日から 8 日分（当日＋7日先）。NHK 番組表 API の情報提供期間の上限 |
| サマリ | 対象期間のピタゴラ系放送を一覧化した、週 1 回送る 1 通のメッセージ |
| 定時放送 | Eテレ平日 6:45-6:55 / 18:40-18:50、総合早朝 4 時台の「ミニ」など、繰り返し放送される枠 |
| 特別版 | 定時放送以外の時間帯に放送される回 |

## データモデル

### 放送

| 属性 | 内容 |
|---|---|
| 番組名 | `▽` より前の部分。例: `ピタゴラスイッチ` |
| サブタイトル | `▽` より後の部分。例: `紙コップコップ暗号`。複数ある場合は `▽` で連結されている |
| 開始日時 | 放送開始の日時（JST） |
| 終了日時 | 放送終了の日時（JST） |

## モデル上の決定と根拠

### 定時放送と特別版をシステムは区別しない

用語としては定義するが、判定処理は持たない。番組名に「スペシャル」が含まれる場合もあるが、それはサブタイトル内の語であり、番組名からは特別版かどうかを判別できない。全放送を通知することで判定ロジックそのものを不要にする。

### 番組名とサブタイトルは `▽` で分割する

実際の番組表には以下の表記が存在する。

```
ピタゴラスイッチ▽紙コップコップ暗号
ピタゴラスイッチ　▽じゃがいも会議はつづく
ピタゴラスイッチ　ミニ▽新しい生物▽パタトクカシー
```

番組名の直後に全角スペースが入る揺れがあるため、分割後に正規化する。

### 対象判定は「ピタゴラ」の部分一致

先頭一致では `大人のピタゴラスイッチ` を取りこぼす。部分一致であれば 3 シリーズすべてを 1 つの条件で拾える。

### 放送局を属性として持たない

取得対象は E テレと総合の 2 波だが、放送局は API 呼び出しの引数であって放送の属性ではない。放送日時が分かれば番組表で局を確認できるため、サマリにも表示しない。

### 放送データを永続化しない

NHK 番組表 API の規約が、情報提供期間を超えたデータの保持を禁止している。また週 1 サマリ方式では前回の通知内容を保持する必要がないため、永続化する動機もない。
